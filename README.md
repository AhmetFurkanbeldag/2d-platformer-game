# 2D Platformer Project 🎮

Bu proje, Unity oyun motoru kullanılarak geliştirilmiş bir 2D Platformer oyunudur.

## 🌟 Özellikler
- 2D Platform mekanikleri (Zıplama, Koşma, vs.)
- Düşmanlar ve engeller
- Can (Sağlık) sistemi
- Puan ve toplanabilir objeler
- Bölüm (Level) tasarımları

## 🛠️ Kullanılan Teknolojiler
- **Oyun Motoru:** Unity 3D
- **Programlama Dili:** C#
- **Sürüm Kontrolü:** Git

## 🚀 Kurulum & Çalıştırma

Bu projeyi bilgisayarınızda çalıştırmak için aşağıdaki adımları izleyebilirsiniz:

1. Bu depoyu (repository) bilgisayarınıza klonlayın:
   ```bash
   git clone https://github.com/KULLANICI_ADIN/REPO_ADIN.git
   ```
2. Unity Hub'ı açın.
3. `Add` veya `Open` butonuna tıklayarak projenin bulunduğu klasörü seçin.
4. Unity'nin projeye uygun sürümüyle projeyi açın.
5. `Assets/Scenes` klasörü altındaki uygun sahneyi açarak **Play** tuşuna basın.

## 📂 Proje Yapısı
- **Assets/Scripts:** Oyunun temel mekaniklerini ve kontrollerini sağlayan C# betikleri.
- **Assets/Prefabs:** Tekrar kullanılabilir oyun objeleri (Karakter, düşman, platform vs.).
- **Assets/Scenes:** Oyunun bölümleri (Leveller).
- **Assets/Environment:** Oyunda kullanılan 2D çizimler, zeminler ve ortam grafikleri.
- **Assets/Audio:** Ses efektleri ve müzikler.
- **Assets/Character:** Karakter animasyonları ve görselleri.
